# تطبيقاتي حسب التاريخ

تطبيق أندرويد بسيط:
- يعرض كل التطبيقات المثبتة على الجهاز **من الأقدم للأحدث** حسب تاريخ التثبيت (وتاريخ آخر تحديث إذا موجود).
- جنب كل تطبيق زر **حذف** يفتح شاشة إلغاء التثبيت تبع النظام.
- القائمة بتتحدث لحالها بعد الحذف.
- من القائمة فوق: تبديل الترتيب (الأقدم/الأحدث أولاً)، إظهار تطبيقات النظام، تحديث.

بدون أي مكتبات خارجية — Kotlin + Android framework فقط. minSdk 21، targetSdk 34.

## طريقة 1: Android Studio
1. فك الضغط وافتح المجلد `AppsByDate` من Android Studio.
2. استنى الـ Gradle sync.
3. `Build > Build App Bundle(s) / APK(s) > Build APK(s)`.
4. الملف بيطلع هون: `app/build/outputs/apk/debug/app-debug.apk`.

## طريقة 2: GitHub (بدون كمبيوتر قوي)
1. اعمل repo جديد وارفع ملفات المشروع كلها (مع مجلد `.github`).
2. روح على تبويب **Actions** — البناء بيشتغل لحالو.
3. بعد ما يخلص (~3-5 دقايق) افتح الـ run ونزّل **AppsByDate-apk** من قسم Artifacts.
4. فك الضغط وثبّت `app-debug.apk` على الموبايل (لازم تسمح بالتثبيت من مصادر غير معروفة).
